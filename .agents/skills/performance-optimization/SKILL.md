# Performance Optimization
Preserve sharp project images and working Next.js image handling. Track LCP, INP, CLS, response failures and bundle changes where measurable. Animate opacity and transform instead of expensive layout, shadow or full-screen blur properties; never rerender React at frame rate. Avoid duplicate animation engines, long decorative delays and unnecessary 3D. Prefer static content and lazy-loaded optional visuals. Measure representative desktop/mobile routes, avoid unrelated optimization changes, and report build-environment limitations honestly.
