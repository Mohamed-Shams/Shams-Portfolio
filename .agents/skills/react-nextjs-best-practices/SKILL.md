# React & Next.js Best Practices
Inspect existing components and callers before editing. Render content server-side for search and accessibility, isolate browser APIs to effects, and keep hydrated initial output consistent. Use `next/image` and `next/link`; preserve locale-aware paths and metadata. Cancel timers, listeners and observers; design effects to tolerate React Strict Mode replays. Keep imports and animations minimal; prefer isolated components and existing conventions. Run `npm run typecheck` and appropriate production builds after substantive changes.
