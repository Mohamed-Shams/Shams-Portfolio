# Playwright / Browser Testing
Prefer the installed `@playwright/test` / `playwright` and an available Chromium or Edge browser. For visual changes, compare the actual current page against the committed baseline at matching viewport sizes. Capture screenshots, video of actual transitions, and browser errors. Include English/Arabic desktop/mobile, correct RTL, reduced-motion and fresh versus returning session tests when relevant. Assert runtime behavior and inspect images instead of treating a test's pass status as visual approval. Keep evidence out of git unless requested.
