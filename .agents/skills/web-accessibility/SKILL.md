# Web Accessibility
Check semantic heading order, labels, landmarks, keyboard focus and link purpose. Ensure interactive overlays do not block navigation or trap focus. Respect `prefers-reduced-motion` at startup; no-JavaScript visitors must still see primary content. Verify `lang`, `dir`, reading order, horizontal motion direction and Alexandria font in Arabic, and keyboard focus visibility in both locales. Use actual browser checks and axe when available; record meaningful issues and fixes.
