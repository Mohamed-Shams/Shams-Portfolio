No unverified LinkedIn or certificate URLs. 7K+, 10K+, 1.3K+ are team project scale. Employer start September 2024 and POC start June 2024 preserved as supplied, without inference.

Asset provenance: portrait.webp is the original attached portrait, converted losslessly in composition (WebP compression only). Industrial images and secondary monochrome portrait are extracted from the user-supplied reference board. Industrial crops are labeled illustrative, never actual project photos. They are low resolution and will not match high-resolution source photography. No new portrait or invented project photography was generated. Google Fonts supplies requested fonts. Case-study gallery plates (src/components/ProjectArt.tsx) are original SVG illustrations drawn for this site — no third-party imagery and no depicted project documentation. Brand glyph paths come from Simple Icons v16 (CC0 1.0), used unmodified.

Known visual differences: supplied portrait has different lighting/crop/background than the composited desktop reference; original face preserved. Industrial thumbnail crops are low-resolution; the homepage hero and project cards blend these with the supplied portrait rather than claiming recovery of the original layered artwork. About portrait uses reference crop. Certification plates use vector issuer marks for AWS, Dataiku and Siemens; Ignition and AVEVA keep the supplied raster crops at native resolution. Contact globe is a geometric SVG approximation. Case-study galleries are original vector illustrations (per-project scene, verified four-step architecture, operations view) carrying an explicit illustrative-artwork disclaimer. No theme toggle: dark reference is preserved.
