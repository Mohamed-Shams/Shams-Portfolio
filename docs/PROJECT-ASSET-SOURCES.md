# Project media provenance and quality audit

This file records the source, usage status and pixel audit for the primary
project imagery introduced by `feature/project-media-consistency`.

The seven photographs below are **illustrative photography**. They are not
presented as photographs of the named client projects. Each source page was
published by its creator on Unsplash and is used under the Unsplash License:
https://unsplash.com/license

Only resizing and WebP encoding were applied to the downloaded photographs.
No AI upscaling, fabricated detail, sharpening pass or generative image edit
was used. The stored covers retain their source aspect ratio; the UI performs
responsive `object-fit: cover` cropping from the same file in every context.

## Signature provenance

`public/assets/signature.webp` is the retained 138×33 raster source from the
original design board. It remains in the repository only as the authenticity
reference for the handwriting.

`public/assets/signature.svg` is a path trace of those same visible strokes.
The dark raster background was removed before tracing; no cursive font,
replacement handwriting, AI generation or invented strokes were introduced.
The SVG has a 1104×264 view box and therefore remains sharp at desktop and
retina sizes while preserving the source signature's 138:33 aspect ratio.
